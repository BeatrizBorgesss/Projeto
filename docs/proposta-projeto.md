# 📌 Proposta do Projeto

## Nome do Projeto

Hora do Remédio

---

## Objetivo

Desenvolver um sistema simples e intuitivo para auxiliar pessoas no controle de medicamentos e horários.

---

## Problema

Muitas pessoas, principalmente idosas, possuem dificuldades para lembrar os horários corretos de seus medicamentos.

---

## Público-alvo

- Pessoas idosas
- Cuidadores
- Familiares

---

## Funcionalidades

- Cadastro de medicamentos
- Cadastro de horários
- Histórico simples
- Lembretes básicos

---

## Diferenciais

- Interface intuitiva
- Letras maiores
- Facilidade de uso
- Organização visual simplificada
