# 📋 Requisitos do Sistema

## Requisitos Funcionais

### RF01
O sistema deve permitir o cadastro de medicamentos.

### RF02
O sistema deve permitir definir horários para os medicamentos.

### RF03
O sistema deve exibir os medicamentos do dia.

### RF04
O usuário poderá marcar medicamentos como tomados.

### RF05
O sistema deverá armazenar um histórico simples dos medicamentos tomados.

### RF06
O sistema deverá emitir lembretes básicos para os horários cadastrados.

---

## Requisitos Não Funcionais

### RNF01
O sistema deverá possuir interface simples e intuitiva.

### RNF02
O sistema deverá ser de fácil utilização para pessoas idosas.

### RNF03
O sistema deverá possuir letras legíveis e boa organização visual.

### RNF04
O sistema deverá armazenar as informações localmente.
