# 📱 Protótipo do Sistema

## Nome do Sistema

Hora do Remédio

---

## Objetivo do Protótipo

O protótipo tem como objetivo representar de forma simples as principais telas do sistema, priorizando uma interface intuitiva, organizada e de fácil uso para pessoas idosas.

---

## Tela 1 - Tela Inicial

A tela inicial deverá apresentar o nome do sistema e botões de acesso rápido.

### Elementos da tela

- Nome do sistema: Hora do Remédio
- Botão: Medicamentos do Dia
- Botão: Cadastrar Medicamento
- Botão: Histórico
- Botão: Configurações

---

## Tela 2 - Medicamentos do Dia

Essa tela exibirá todos os medicamentos programados para o dia atual.

### Informações exibidas

- Nome do medicamento
- Dosagem
- Horário
- Status: Pendente ou Tomado
- Botão para marcar como tomado

---

## Tela 3 - Cadastro de Medicamento

Tela utilizada para registrar um novo medicamento no sistema.

### Campos

- Nome do medicamento
- Dosagem
- Horário
- Observações
- Botão Salvar

---

## Tela 4 - Histórico

Tela responsável por exibir os medicamentos que já foram tomados.

### Informações exibidas

- Nome do medicamento
- Data
- Horário
- Status

---

## Tela 5 - Lembretes

Tela destinada à organização dos lembretes cadastrados.

### Funcionalidades

- Visualizar lembretes ativos
- Editar horário do lembrete
- Excluir lembrete

---

## Acessibilidade

Como o sistema é voltado principalmente para pessoas idosas, o protótipo deverá considerar:

- Letras grandes
- Botões grandes
- Cores com bom contraste
- Poucas informações por tela
- Linguagem simples
- Navegação fácil
