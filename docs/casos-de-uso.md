# 👤 Casos de Uso

## Objetivo

Os casos de uso representam as principais interações do usuário com o sistema Hora do Remédio.

---

# Caso de Uso 01 - Cadastrar Medicamento

## Descrição

Permite que o usuário registre um novo medicamento no sistema.

## Ator

Usuário

## Fluxo Principal

1. O usuário acessa a tela de cadastro.
2. O usuário informa o nome do medicamento.
3. O usuário informa a dosagem.
4. O usuário define o horário.
5. O usuário clica em salvar.
6. O sistema registra o medicamento.

---

# Caso de Uso 02 - Visualizar Medicamentos do Dia

## Descrição

Permite visualizar todos os medicamentos programados para o dia atual.

## Ator

Usuário

## Fluxo Principal

1. O usuário acessa a tela inicial.
2. O usuário seleciona “Medicamentos do Dia”.
3. O sistema exibe os medicamentos cadastrados para o dia.

---

# Caso de Uso 03 - Marcar Medicamento como Tomado

## Descrição

Permite marcar um medicamento como já tomado.

## Ator

Usuário

## Fluxo Principal

1. O usuário acessa a lista de medicamentos.
2. O usuário seleciona um medicamento.
3. O usuário clica em “Marcar como Tomado”.
4. O sistema atualiza o status do medicamento.

---

# Caso de Uso 04 - Consultar Histórico

## Descrição

Permite visualizar o histórico de medicamentos já tomados.

## Ator

Usuário

## Fluxo Principal

1. O usuário acessa a tela de histórico.
2. O sistema exibe os medicamentos registrados anteriormente.

---

# Caso de Uso 05 - Configurar Lembretes

## Descrição

Permite configurar lembretes de horários dos medicamentos.

## Ator

Usuário

## Fluxo Principal

1. O usuário acessa as configurações.
2. O usuário define os horários de lembrete.
3. O sistema salva as configurações.
