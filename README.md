# Hora do Remédio

Sistema de controle de medicamentos para pessoas idosas.

## Objetivo

Desenvolver uma aplicação simples para auxiliar pessoas idosas na organização e acompanhamento do uso de medicamentos.

## Funcionalidades

- Tela inicial personalizada
- Cadastro de medicamentos
- Medicamentos do dia
- Histórico de medicamentos tomados
- Sistema de lembretes
- Navegação entre telas

## Tecnologias utilizadas

- React Native
- Expo
- TypeScript
- Expo Router

## Estrutura do Projeto

```text
src/
 ├── screens/
 ├── services/
 ├── database/
 └── app/
```

## Como executar

```bash
npm install
npx expo start
```

Projeto MVP funcional concluído.
